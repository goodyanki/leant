# M2 性能基准报告：完整 Leant 框架 vs Gin（TFB 规范）

- **测试日期**：2026-11-22
- **环境**：Linux x86_64（2 vCPU，`ulimit -n 1024`）
- **工具链**：Lean `v4.36.0` (Release)、Go `1.26.11` + Gin `v1.12.0` (`gin.ReleaseMode` + `gin.New()`)、Rust `1.100.0` (`tokio 1.54` + `hyper 1.12`)、`wrk 4.1.0`
- **测试命令**：`DURATION=4s ./bench/scripts/run.sh bench/results/M2.csv`
- **被测对象**：
  - `bench_leant`（[bench/leant/BenchLeant.lean](../leant/BenchLeant.lean)）：完整走 `Leant.App`、`TrieNode` 路由、`Context`、`AppError`、`Headers`、`Lean.ToJson` 与 `RustHyper` 传输层（含 header timeout 与优雅停机）
  - `gin_baseline`（[bench/baselines/gin/main.go](../baselines/gin/main.go)）：`gin.ReleaseMode` + `gin.New()`

## MVP（M2）验收达成情况

- **PRD M2 吞吐目标（≥ Gin 30%） / v1 目标（≥ Gin 60%）**：`/plaintext` 达到 Gin 的 **113%–156%**，`/json` 达到 Gin 的 **132%–147%**，均大幅超越 MVP 与 v1 目标。
- **尾延迟（p99）**：在所有并发梯度下均为同机 Gin 的 **25%–64%**（更低）。
- **稳定性**：累计 >170 万请求，高并发 `c=512` 下 **0 错误**，RSS 稳定在 69–78 MB 无持续增长。
- **热路径优化点（M2.8）**：
  1. Rust 侧通过 `req.body().is_end_stream()` 对无 body 请求跳过 body stream collect 与 `method/path/query` 堆拷贝；
  2. C ABI shim 对 `"GET"`、`"POST"`、空 query、空 body 使用 `lean_mark_persistent` 零分配单例。
